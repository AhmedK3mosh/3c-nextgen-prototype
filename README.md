# 3C NextGen Learning Experience — Prototype

High-fidelity interactive Arabic/Gulf-oriented product prototype based on the product audit and the proposed 3C learner-experience evolution.

## Included flows
- Landing
- Smart assessment
- Learner DNA / profile
- Personalized learning path
- Today / daily missions
- AI Coding Coach
- Project Studio
- Parent Intelligence dashboard

## Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel
1. In Vercel choose **Add New → Project**.
2. Import `AhmedK3mosh/3c-nextgen-prototype`.
3. Framework preset: **Next.js**.
4. Deploy.

No environment variables are required for this prototype.

## Status
Clickable UX/product demo with mock data. It does not include authentication, database, payments, real LMS integration, or a live AI model.
